# Digital Weighing Systems — Website Redesign

A full redesign of the corporate website for **Digital Weighing Systems (P) Ltd**, an ISO 9001:2015 certified manufacturer of electronic weighing systems based in Bilaspur, Chhattisgarh, India — in business since 1994.

Rebuilt from a legacy PHP site into a modern, responsive, animated MERN-stack application.

> **Status:** In progress / client review. Not yet publicly launched.

---

## Tech Stack

**Frontend**
- React (Vite)
- Tailwind CSS
- Framer Motion (animations, scroll reveals)
- React Router
- react-helmet-async (per-page SEO meta tags)
- Lucide React (icons)

**Backend**
- Node.js + Express
- MongoDB (Mongoose)
